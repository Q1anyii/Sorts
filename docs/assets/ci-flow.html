③部署阶段 默认关闭 · 仅手动触发且勾选 deploy 时执行
deploy 部署到目标服务器
appleboy/ssh-action@v1.0.3 → ECS（host / user / SSH key 走 Secrets）
cd /opt/sorts → docker login
compose pull + up -d （中间件）
compose --profile app pull + up -d --no-build （6 服务）
--no-build：服务器只拉镜像不构建
健康检查（就绪判定）
轮询 gateway:8080/actuator/health
最多 24 次 × 5s（command_timeout 10m）
必须 grep '"status":"UP"'
不能只看 HTTP 200 —— 曾出现「假健康」：200 但 body 是业务 Result{code:500}
失败 → 打印 sorts-gateway 日志 100 行 → exit 1
开关两个开关决定的链路形态

触发 → 测试 → 镜像构建（不推送） → 结束

勾选 push_images
触发 → 测试 → 镜像构建 → 登录 ACR 并推送 → 结束
tag 为 :{short-sha} 与 :latest，需 ACR_* Secrets
再勾选 deploy
触发 → 测试 → 镜像构建 → 推送 → SSH 部署 + 健康检查
需 ECS_* Secrets；health 必须 UP 才算成功
