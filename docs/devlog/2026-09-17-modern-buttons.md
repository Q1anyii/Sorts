# Devlog · 2026-09-17 · 主计划/子计划按钮现代化 + 文案主题化

## 需求
用户反馈主计划与子计划的操作按钮「复古」，且页面描述不够贴合项目主题（织锦/梭子/穿梭/落梭）。

## 实现
### 1. 文案主题化
- 主计划页说明：`长时间计划容器…` → **「主线 · 织机：把长期目标织成主计划，将每日日程挂载为子计划；每一次落梭，进度都在织机上自动聚合。」**
- 空状态：`还没有主计划…` → **「还没有织上主线。把长期目标（如秋招备战、项目攻坚）织成主计划，再将每日日程挂载为子计划，让每一天都有迹可循。」**

### 2. 按钮现代化（织锦流光风格：柔和胶囊 + 细描边 + hover 填充）
新增 CSS 类（style.css）：
- `.btn-ghost`：半透明白胶囊 + 描边，hover 主题色填充
- `.btn-ghost-success`（开梭/续梭，浅绿）/ `.btn-ghost-warn`（暂停，浅琥珀）/ `.btn-ghost-brand`（落梭/完成，浅主题蓝）
- `.btn-icon-sm`：30px 圆形图标钮（编辑 ✎ / 删除 🗑），`danger` 变体红色系

替换点：
- **主计划卡片**：`◈ 详情`（ghost）+ `▶ 开梭`（ghost-success）+ `⏸ 暂停`（ghost-warn）+ `✓ 完成`（ghost-brand）+ `✎` `🗑`（圆形图标钮）
- **织程列表**：`▶ 开梭 / ⏸ 暂停 / ▶ 续梭 / ⏹ 落梭` 改为 ghost 胶囊，`✎ / ✕` 改为圆形图标钮（✕ → 🗑）
