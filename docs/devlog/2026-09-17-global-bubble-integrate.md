# Devlog · 2026-09-17 · 全局气泡整合 + 主计划盒子活动行 + 按钮视觉

## 需求
用户反馈三点：
1. 全局气泡只有主计划文字（子计划 0/9），没有把**正在执行的子计划**放进去；由于子计划只能执行一个，期望像主界面盒子一样：主计划在上、子计划直接内嵌（含计时与穿梭按钮）。
2. 主界面（今日经纬）的主计划气泡没有可操作的计划按钮——期望盒子内正在执行的子计划可直接操作。
3. 计划进行时气泡右侧出现「白色椭圆」，存疑是否为 bug。

## 实现
### 1. 全局气泡整合（跨页面悬浮）
- 原实现：主计划 + 子计划**两个独立气泡**（上下堆叠）。
- 新实现：**一个气泡**——主计划头（状态/天数/标题/进度/子计划计数 + 暂停/续梭/完成）+ **内嵌执行中的子计划行**（`.gtb-child-inline`：计时 + 标题 + 暂停/续梭/落梭/取消），点击子计划行跳转今日经纬。
- 无活跃主计划时保持原「仅子计划」独立气泡（v-else-if）。

### 2. 今日经纬盒子活动行
- 新增 `activeBoxChild` computed：主计划 children 中正在执行/暂停的子计划（activeSchedule 属于该主计划时）。
- 盒子顶部**置顶活动行**：色点 + 标题 + `formatTimer(elapsedSeconds)` 计时 + ⏸/▶/⏹/✕ 穿梭按钮（`btn-xs` 圆形小钮）。
- 其余子计划排除活动项（`nonRunningBoxChildren`），按原三档（≤3 完整行 / ≤8 压缩行 / >8 任务点）展示，避免重复。

### 3. 「白色椭圆」定位与处理
- 排查确认：非 bug——为**半透明白圆形操作按钮**（暂停/完成，`rgba(255,255,255,.2)` 圆钮叠加在深蓝渐变上）的观感。
- 优化：`.global-timer-bubble .gtb-btn` 增加 1px 白色细边 + 阴影，按钮更精致、不再像「白椭圆」。

### 4. 其他
- `.active-timer .btn-end` 统一为半透明白 + 主题色文字（主计划气泡完成按钮，去掉纯白大块）。
