# Devlog · 2026-09-17 · AI 多日规划建议面板分页

## 背景

用户反馈 AI「多日规划建议」面板把未来一周全部规划（7 天 × 多条）一次性平铺在长列表里，页面无限延长，
要求实现分页查询。

## 实现（纯前端，不改后端）

规划建议已全量存在于会话快照（/ai/conversations/{id}），因此分页为**展示层分页**，勾选状态仍为全局索引。

- `frontend/js/app.js`：
  - 新增 `PLAN_DAY_PAGE_SIZE = 2`（每页 2 天）、`planPage`、`planTotalPages`、`pagedPlanGroups` computed
    （按天分组后切片）、`prevPlanPage` / `nextPlanPage`；
  - `watch(planTotalPages)` 采纳/清空后页数变少时自动钳制当前页；
  - 新规划生成（sendAiMessage）、会话恢复（applyConversation）、清空会话（resetAiChatState）均重置回第 1 页。
- `frontend/index.html`：分组渲染 `aiGroupedSuggestions` → `pagedPlanGroups`；分组下方插入分页栏
  （上一页 / 第 x / N 页 · 共 M 条 / 下一页），仅当总页数 > 1 时显示。
- `frontend/css/style.css`：`.plan-pager` 分页栏样式（顶部虚线分隔）。
- 资源版本号 `?v=20260917-1` → `20260917-2`（配合 nginx no-cache）。

## 关键设计

- **按天分页而非按条分页**：保持「日期分组」的语义完整，一页 = 2 个完整日期组（约 4-6 条），页面长度可控。
- **勾选全局化**：`aiSelectedIndices` 存的是建议全局下标，翻页不影响已勾选；跨页「批量采纳」数量保持正确。
- **默认全选语义不变**：生成后默认全选，用户逐条/按天/全选按钮取消，均可跨页操作。

## 验证（bu 实测，localhost:8088）

| 项 | 结果 |
|---|---|
| 1 天/≤2 天数据时（totalPages=1）分页栏隐藏 | ✅ |
| 生成 14 条（7 天）规划 → 第 1 页仅显示 2 天（09-17/09-18，4 条），分页栏「第 1 / 4 页 · 共 14 条」 | ✅ |
| 下一页 → 09-19/09-20；上一页 → 回第 1 页 | ✅ |
| 第 1 页取消勾选 1 条（15/16 已选）→ 翻到第 2 页「批量采纳（15）」保持全局 | ✅ |
| 全选按钮：15/16 → 16/16 | ✅ |
| 清空当前会话（确认弹窗）→ 建议清空、分页栏隐藏 | ✅ |
