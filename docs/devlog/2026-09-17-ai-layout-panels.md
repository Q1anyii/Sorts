# 2026-09-17 梭灵三栏布局：适配窗口 + 折叠/展开 + 拖拽调宽

## 需求
1. 会话 / 对话 / 规划建议三栏适配窗口大小，不留白、不溢出
2. 三栏可独立折叠；对话窗口始终显示
3. 折叠按钮内嵌模块头部（豆包风格线条图标）；面板被折叠后，对话窗口顶部左右出现展开按钮
4. 三栏同时打开时可拖拽分隔条动态调宽

## 实现（frontend 主版 CDN）
- 布局：grid `250px 1fr 1fr` → flex `.ai-layout`（`height: calc(100vh - 196px); min-height: 440px`），
  三栏等高 `align-items: stretch`；会话 250px / 规划建议 340px 固定可拖，对话 `flex: 1 1 auto` 自动占剩余
- 高度适配：`.ai-chat-messages` 固定 400px → `flex: 1; min-height: 0`（内部滚动），`.conv-sidebar` 去掉 min-height 420px
- 折叠：`aiPanels = { sidebar, chat, plans }`，对话锁定常显（`toggleAiPanel` 对 'chat' 直接 return，
  头部无折叠按钮、无「始终显示」标注）
- 展开：对话窗口顶部 `.ai-chat-bar` 左右两侧，仅当对应面板被折叠时出现展开按钮
  （左侧 `v-if="!aiPanels.sidebar"` 展开会话，右侧 `v-if="!aiPanels.plans"` 展开规划建议）
- **按钮统一收拢（v2）**：会话 / 规划建议面板头部不再放折叠按钮，所有面板控制集中在对话窗口
  顶部两端常驻按钮（豆包风格线条图标）：左侧按钮控制会话（显示时 `‹` 隐藏 / 隐藏时 `›` 展开），
  右侧按钮控制规划建议（显示时 `›` 隐藏 / 隐藏时 `‹` 展开），图标随状态切换，位置固定不跳
- 占满不留白：折叠任一侧后对话 `flex: 1` 自动伸展；`flex-wrap` 响应式断点 640px（极窄屏堆叠）
- 拖拽调宽：`.ai-resizer` 分隔条（6px，hover 高亮），`startAiResize` 监听 mousemove/mouseup，
  sidebar 条在面板右侧（向右拖变宽）、plans 条在面板左侧（向右拖变窄），宽度限幅 180–420 / 260–640
- 兜底：页头右侧「恢复全部面板」按钮仅当有面板被折叠时出现（防止全隐藏后无法恢复）

## 关键坑
1. 初次实现把响应式断点设 1100px，测试视口 720px 恰好命中 → 三栏被 wrap 堆叠、高度错乱
   （sidebar 211 / chat 568 / plans 709 不等高）；断点下调至 640px 后桌面三栏行为正确
2. 全隐藏后没有任何按钮可恢复 → 增加页头兜底「恢复全部面板」（条件渲染，平时不出现，不违背「不独立放右上角」）

## 验证
- 三栏等高 585/677px；折叠会话 → 对话 334→490px 自动占满，顶部左侧出现展开按钮，点击恢复
- 折叠规划建议 → 对话 334→580px 占满，右侧展开按钮恢复；恢复后三栏复原
- 对话栏无折叠按钮、无「始终显示」文字；拖拽条 2 条存在
