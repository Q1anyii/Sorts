# 梭子 SORTS · 主题设计规范

> 主题内核：**光阴似箭，日月如梭**
> 产品名「梭子」取自织布之梭 —— 梭来往穿梭、经纬交织，正如时间在生命中穿行。箭与梭，都是「快」的意象，因此产品的一切设计都要回答一个问题：**如何让流逝的时间被看见、被留住。**

---

## 一、主题方向选型（三方案对比）

| 方案 | 概念 | 收益 | 风险 | 结论 |
|---|---|---|---|---|
| **A. 织锦流光**（选定） | 时间即织布：日为经、事为纬，日历是一幅正在织成的锦缎 | 与「梭」强绑定，视觉语言独一无二；日历/统计天然适配网格与线性质感；延展性好（皮肤=锦纹） | 隐喻偏抽象，需要克制表达，否则视觉噪音高 | ✅ 主方案 |
| B. 星轨穿梭 | 宇宙、流星、时间轴轨道 | 科技感强、动效好做，前端实现成本低 | 审美同质化严重，与「梭子」品牌名弱关联 | ❌ 放弃 |
| C. 日晷晨昏 | 日晷投影、光影随真实时间流转 | 古典时间感强，仪式感高 | 明暗对比强烈，长时间使用易疲劳；暗色与数据可读性冲突 | ⚠️ 吸收其「时间刻度」元素 |

**最终方案：A 为主，吸收 B 的流光质感、C 的时间刻度感。**
设计原则：**克制的东方感 + 现代数据可读性**，装饰元素只出现在品牌位（登录页、空状态、报告页头），功能区域（日历、计时器、数据表）保持信息密度优先。

## 三、设计令牌（Design Tokens）

> 以 **浅色主题** 为默认（与 IDE 浅色一致），后续扩展暗色「夜梭」主题。
> 前端落地为 CSS 变量，见 `frontend/src/styles/tokens.css`（M6 实施）。

| Token | 色值 | 用途 |
|---|---|---|
| `--sorts-ink` | `#1B2A41` | 主文字 / 标题 / 深墨蓝 |
| `--sorts-ink-soft` | `#4A5B70` | 次级文字 |
| `--sorts-moon` | `#F7F5EF` | 页面底色（月白） |
| `--sorts-paper` | `#FFFFFF` | 卡片底色 |
| `--sorts-gold` | `#C89B3C` | 品牌主色（梭金）：主按钮、进行中状态 |
| `--sorts-arrow` | `#3D7EA6` | 信息色（箭青）：已完成、链接 |
| `--sorts-sand` | `#E6DCC3` | 光阴砂（积分）相关 |
| `--sorts-late` | `#C0563B` | 超时 / 逾期（赭红） |
| `--sorts-line` | `#E4E1D8` | 分割线 / 网格线 |

**状态色语义**（日程状态机）

| 状态 | 颜色 | 视觉表现 |
|---|---|---|
| 待开始（PENDING） | 时序灰 `#6B7280` | 细边框、无填充 |
| 穿梭中（RUNNING） | 梭金 `#C89B3C` | 渐变流光边框 + 呼吸动效 |
| 已暂停（PAUSED） | 浅金 + 斜纹 | 暂停图标 + 已耗时长 |
| 已落梭（COMPLETED） | 箭青 `#3D7EA6` | 实心圆点 + 完成勾 |
| 已取消（CANCELLED） | 灰 | 删除线 |
| 已超时（OVERTIME） | 赭红 `#C0563B` | 红色描边 |

## 四、关键视觉元素

1. **梭形（Shuttle）图标**：两端尖、中间宽的纺锤形，用于 logo、加载动画、进度指示。
2. **经纬网格**：日历背景为极淡的经纬线（1px `--sorts-line`），日程块覆盖其上，形成「织锦」观感。
3. **流光动效（shimmer）**：计时中的日程卡片边框做 2s 循环的金色渐变流动 —— 呼应「时光流逝」，仅在活跃项出现，避免干扰。
4. **穿梭过场**：路由切换时，梭形元素从屏幕一侧掠过（200ms），呼应「日月如梭」。
5. **时间刻度**：统计页图表纵轴使用刻度尺样式（吸收方案 C）。

## 五、字体

- 正文：`"PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", system-ui`
- 数字/计时器：`"JetBrains Mono", "SF Mono", ui-monospace`（等宽，避免秒数跳动时宽度抖动）
- 品牌标题：`"Source Han Serif SC", "Songti SC", serif`（登录页 slogan、报告标题用衬线体，强化东方感）
