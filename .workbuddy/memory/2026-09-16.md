### 关键设计决策
- **时长口径统一为「秒」**：`t_schedule.actual_duration`、`t_time_record.duration`、统计的 totalFocusTime/totalDuration 全部是秒；仅 `plannedDuration` 是分钟。与前端演示版、api-spec 一致（前端自行 /60）

### 接口层的硬坑：同一路径既要 JSON 又要 SSE
Spring MVC 按**方法声明的返回类型**挑返回值处理器 → 返回类型写 `Object` 时 `SseEmitter`
不会被 SSE 处理器接管，而是被 Jackson 序列化成普通对象（前端收不到事件流）。
→ 用 `params` 条件拆成两个处理方法：
  - `/chat`、`/summary/daily`：`!stream=false` → SSE（默认流式），`stream=false` → JSON
  - `/plan`：`!stream=true` → JSON（默认非流式），`stream=true` → SSE
  传输方式由 query 参数决定；请求体里的 stream 字段仅契约兼容保留。

  `ToolRegistry` 收口「声明过滤 → 执行前复核 → 异常兜底」
- **ToolJsonCodec**：工具层专用 ObjectMapper，时间固定 ISO-8601 —— 复用全局 mapper 时若被改成

- 秒→分钟/比率→百分比在边界完成；趋势截 30 点、pageSize ≤50、批量 ≤20（上下文预算）
- 对话上下文只存「用户问 + 最终答」存 Redis（TTL 12h）：中间 tool 结果是时效性快照
- 工具循环达上限后**补一次不带工具的调用**强制出结论，否则用户拿到空回复

- 单测：common 19 · gateway 21 · user 16 · schedule 67 · ai 103 · notification 51 · mall 44 = **321**

### 关键决策
- **内部接口一律 `/internal/**` + `@InternalApi` 注解**：网关只路由 `/api/v1/**`，该前缀外部不可达；注解代替路径前缀判断（前缀改名就静默失去保护）。未配置凭证时 **fail-closed**
- **Feign 出站按路径白名单自动加凭证**（`sorts.internal.paths`，默认 `/internal/`、`/api/v1/users/points/change`）——需要人记住的安全约定迟早会漏
- **购买顺序：加锁 → 扣积分 → 本地事务落库**，不可颠倒（积分不足是最常见失败，先扣可在未占库存时快速失败；反向则失败要删订单，账目不该被删）
- **防超卖双保险**：Redisson 按商品加锁 + 条件更新 `UPDATE ... WHERE stock > 0`；无限库存(-1)跳过扣减，补偿带 `stock >= 0` 条件（否则会把 -1 补成 0 变售罄）
- **Redis 不可用时购买 fail-closed**：库存与积分不允许无互斥保护裸奔
- **提醒幂等 at-most-once**：`t_reminder_log` 唯一键 + `INSERT IGNORE` 先占额度再发通知；免打扰期间**不占额度**，安静时段结束后会自动补上
- **提醒设置不预写空行**：无记录时返回默认值 + `customized=false`（「没有偏好」与「偏好即默认」语义不同）
- 事务性落库放**独立 Bean** `PurchasePersister`（与 M4 的 @Async 同一个坑：同类自调用绕过代理）
- **网关路由顺序即优先级**：`/api/v1/users/wardrobe/**` 同时命中 mall 与 user，mall 必须排在前面，否则转发到用户服务 404

### 新增踩坑
1. `LocalTime.parse("7:00")` 会抛异常（ISO 要求小时两位）→ 手输/历史数据的 `H:mm` 必须用显式 `DateTimeFormatter` 宽松解析，否则一条脏数据就中断整轮提醒扫描
2. `findEffective(Long)` 与 `findEffective(Collection)` 重载后，调用点传 `Collectors.toCollection(...)` 结果会触发方法引用推断歧义 → 改名 `findEffectiveAll` 一次性消除，别在每个调用点加显式类型
3. **`-pl` 只构建单个子模块时 `sorts-common` 从本地仓库解析**（可能是旧版本，报「程序包 com.sorts.common.internal 不存在」）→ 必须 `-pl sorts-common,<目标>` 或加 `-am`
4. Git Bash 无 `bc`，统计用 `awk`；grep 中文输出可能被当二进制，需 `grep -a`

### 新增体系要点

- **三条硬约束**：实心朱砂同屏 ≤3 处；纹样只做底不做主（≤6% 不透明度）；宋体不越界。
