## 遇到的问题与解决

1. **本机 mvn 损坏**（classworlds ClassNotFoundException，PATH 中 E:\develop 下两个安装都坏）
   → 解法：`scripts/mvn.sh` 用 java 直接启动 Maven Launcher，并做 MSYS→Windows 路径转换 + JVM 代理透传
2. **Maven 下载慢**（首次 5m41s）→ 配置 `~/.m2/settings.xml` 阿里云镜像，用户开代理后 48s
3. **Mockito 泛型匹配器歧义**：MyBatis-Plus `insert(T)` / `insert(Collection<T>)` 下 `any(User.class)`、`argThat()`、`captor.capture()` 均编译报「对 insert 的引用不明确」
   → 解法：用 `ArgumentMatchers.<User>any()` 显式类型参数，或 AtomicReference 捕获参数
4. **推送被拒 403**：SSH 所属账户 Q1anyiii 被封停；Q1anyii 的 fine-grained PAT **Contents 只读**
   → 待用户把令牌权限改为 Contents: Read and write 后推送

### 关键设计决策
- **时长口径统一为「秒」**：`t_schedule.actual_duration`、`t_time_record.duration`、统计的 totalFocusTime/totalDuration 全部是秒；仅 `plannedDuration` 是分钟。与前端演示版、api-spec 一致（前端自行 /60）
- **分段计时**：start/resume 开 t_time_record 片段，pause/end/cancel 结算；总时长按全部片段秒数重新求和（不做累加）
- **双重存储**：DB 片段为权威来源，Redis 只缓存「当前片段起点」，键丢失也能靠 DB 正确结算；DB 缺片段时用 Redis 兜底补记
- **落梭奖励**：Feign 调 sorts-user 发 5 光阴砂，失败只告警不回滚（M5 换 MQ 事件，调用方无需改）
- **聚合策略**：一次 listInRange 全量取回后内存按天分组，避免 N+1，单测也无需 mock 复杂 SQL

### 新踩坑（已写入 PROGRESS.md）
1. **MyBatis-Plus 逻辑删除**：配置了 `logic-delete-field: deleted` 后，不能 `setDeleted(1)` + `updateById`（该字段被排除在 SET 之外），必须 `deleteById` 触发生成的逻辑删除 SQL
2. **分页插件必须显式注册** `PaginationInnerInterceptor`，否则 `selectPage` 不拼 LIMIT 会退化成全表查询
3. **MP wrapper 的 `getSqlSegment()` 在纯 Mockito 单测里会抛**「can not find lambda cache」→ 把排序拼装抽成包级可见的纯函数 `buildOrderBy()` 作为测试接缝，不碰 MP 内部
4. **同文件批量编辑有丢失风险**：一次消息里对同一文件发多个 Edit，出现过只落最后一条的情况 → 关键改动后要 grep 校验

## 追加：IDE 可执行化改造（同日 15:40）

### 用户诉求
「如何把这个结构构建成 Maven 项目、直接在 IDE 上执行」——用户给的是 IDEA 项目树截图。

### 诊断（根因）
1. **仓库是「容器目录 + Maven 工程在子目录」结构**：IDEA 打开 `D:\SORTS(梭子)` 时不会导入 `backend/pom.xml`，
   `.idea/modules.xml` 里只有一个空的根模块 → 没有 Maven 面板、源码全飘红、没有任何 Run 按钮。
2. **项目 SDK 被设成了 26**（`misc.xml`），而项目编译目标是 17；Lombok 1.18.34 对 JDK 23+ 支持不完整。
3. 没有运行配置，起三个服务要点三次。

### 顺带查清一个大误诊
「本机 mvn 已损坏」是**错的**。实测：
- 干净 shell：`mvn -v` → `Apache Maven 3.9.15 @ E:\develop`，完全正常
- 沙箱 shell：报 `ClassNotFoundException: org.codehaus.plexus.classworlds.launcher.Launcher`
- 根因：沙箱注入了 `MSYS_NO_PATHCONV=1` + `MSYS2_ARG_CONV_EXCL=*`，**关闭 MSYS 路径转换**；
  Maven 的 `bin/mvn` 是 POSIX sh 脚本，把 `/c/Users/.../plexus-classworlds.jar` 直接交给原生 `java.exe`
- 对照验证：`env -u MSYS_NO_PATHCONV -u MSYS2_ARG_CONV_EXCL bash -c 'mvn -v'` → 成功
- `scripts/mvn.sh` 能用是因为它显式 `cygpath` 转成了 `C:/...`
